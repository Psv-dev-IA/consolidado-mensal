# Identidade visual

Preencha uma vez, salve como `identidade.md` e anexe junto com os relatórios todo mês.
Campo em branco cai no padrão, e o material sai assim mesmo.

**Sobre as cores:** você não precisa preencher nada. A paleta é lida da sua logo, direto do
arquivo que você anexar. Só preencha os campos de cor se quiser sobrepor o que foi lido.

## Como usar todo mês

Anexe na mesma mensagem:

1. Este arquivo preenchido, salvo como `identidade.md`
2. O arquivo da sua logo
3. Os relatórios dos clientes, quantos forem

E escreva: **Consolidado e report de [mês]**

Para o report de mercado sem carteira, escreva: **Só report de [mês]**
